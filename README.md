## Problem Solving Course #7 – Bank System (C++)

This repository contains my work from the seventh Problem Solving course with Dr. Mohammed Abu-Hadhoud. The course focused on solving complex problems, with particular emphasis on file handling and practical system design.

As a final project, I implemented a complete banking system to reinforce and connect the concepts learned throughout the course.

### Project Overview
The project is a simple console-based banking system that allows user management through a command-line interface. The system supports the following operations:
- Add users  
- Update user information  
- Delete users  
- Display users records
- Find user

### Implementation Details
- **File Handling:** Used to store user data persistently. Each user is saved as a single record in a text file with delimiters separating the fields.  
- **Vector (C++ STL):** Utilized to load and manage user data in memory, making operations like reading, updating, deleting, and searching more efficient.  
- **Console Formatting:** Applied the `setw` function to neatly align and format output in the console for better readability.  

### Purpose
This project demonstrates how to integrate multiple core concepts—problem solving, file handling, and data structures—into a cohesive and functional application.
